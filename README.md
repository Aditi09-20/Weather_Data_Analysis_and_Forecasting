# Weather Data Analysis and Forecasting

## Project Overview

This project analyzes historical weather data and develops machine learning models to predict next-day weather conditions.

## Objectives

- Analyze temperature, rainfall, humidity, and wind patterns.
- Explore monthly and seasonal weather trends.
- Build models for next-day weather prediction.
- Compare different machine learning approaches.
- Evaluate model performance using appropriate metrics.

## Project Status

Project setup completed.

## Project Structure

- `data/` — Weather datasets
- `notebooks/` — Data analysis and machine learning notebooks
- `src/` — Python scripts
- `results/` — Graphs, tables, and model results
